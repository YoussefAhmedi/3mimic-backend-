Bulk import YouTube snippets

How to enter the snippets

Paste one snippet per line in this exact order, separating the four columns with the vertical bar |:

YouTube URL with start time | END TIME | LANGUAGE | LEVELS

  • YouTube URL: include a start timestamp, such as ?t=31, &t=1m05s, or ?start=31.
  • End time: seconds (50) or time format (00:50 or 01:10:20).
  • Language: an active language name or code, for example English or en.
  • Levels: one level, or multiple levels separated with semicolons, for example A1;A2. A separate snippet is created for each level.
  • A video is created automatically when its YouTube ID is not already in the database. Existing videos must use the same content language.
  • Blank lines and lines beginning with # are ignored. Repeated snippets are skipped.

Currently active languages: {% for language in available_languages %}{{ language.name }} ({{ language.code }}){% if not forloop.last %}, {% endif %}{% empty %}None available{% endfor %}

Currently active levels: {% for level in available_levels %}{{ level.name }} ({{ level.code }}){% if not forloop.last %}, {% endif %}{% empty %}None available{% endfor %}

Example — copy and edit

https://youtu.be/huPMNLlXFNg?t=31 | 00:50 | English | A1
https://youtu.be/huPMNLlXFNg?t=681 | 11:40 | English | B1
https://youtu.be/huPMNLlXFNg?t=1 | 00:20 | en | A1;A2
https://youtu.be/huPMNLlXFNg?t=601 | 10:20 | English | B1;B2

Important: use | between columns, not commas. The URL's timestamp sets the start; the second column sets the end.
