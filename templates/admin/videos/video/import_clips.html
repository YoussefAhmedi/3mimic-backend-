Import clips (JSON)

One block per video. captions may mix hand-written lines with "Automatic" (= take YouTube's captions live for the parts you did not write). Manual lines win where they overlap. Add quiz to use a clip in the level-placement quiz. Re-importing a clip updates it.

  "video": "https://youtu.be/FkZo43H39OY",
  "lang": "en",
  "clips": [
    { "time": ["00:00:30", "00:00:40"], "level": ["B1", "B1.1"], "captions": ["Automatic"] },
    { "time": ["00:03:22", "00:03:39"], "level": ["B1.1"],
      "captions": [["00:03:22", "00:03:24", "Where's the dragon warrior?"], "Automatic",
                   ["00:03:27", "00:03:30", "You think I'm a fool?"]],
      "quiz": { "question": "Who is being looked for?", "options": ["The dragon warrior", "A fool", "Tyler"], "correct": 1 } }
  ]
}
